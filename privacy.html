MacFiles Backup

Privacy policy

Last updated: October 13, 2026.

MacFiles Backup is a private tool operated by its owner to back up selected files to the owner's Google Drive account. It is not offered as a public service.

Data and permissions

The tool reads files selected by its owner for backup, including their names and filesystem metadata. It uses the Google Drive drive.file scope to create, read, update and remove files in its own backup folder. This scope can also access files the owner explicitly makes available to the app. The configured workflow does not request broad access to existing Drive documents, Gmail, contacts or calendars.

The tool checks the Google account identity, storage quota and backup-folder metadata to confirm that backups use the intended destination. OAuth credentials are retained on the owner's controlled devices to support scheduled backups.

Encryption and storage

Restic encrypts file contents, filenames and backup metadata before they are uploaded. Google Drive stores the encrypted repository. The repository password is kept separately on the owner's controlled devices and in the owner's password manager; it is not uploaded as a plaintext file to the backup folder.

Google can still observe account activity, encrypted object sizes and transfer times. Local operational records may include file paths and errors and are restricted to the owner or authorized system administrators.

Use and sharing

Data is used only to create, maintain, validate and restore backups. The tool does not sell data, use it for advertising, send it to AI models, or publicly share backup files. Google processes storage and authorization requests under its own applicable terms and privacy policy. Use of data received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

Encrypted backup versions are kept according to the owner's configured retention policy. The owner can change that policy or remove the backup repository. Files placed in Google Drive Trash remain subject to Google's trash-retention behavior.

The owner can revoke the application's authorization through Google Account settings. Revoking authorization stops future access but does not delete existing backups; those can be removed separately in Google Drive. Local credentials can also be removed from the configured devices.

This informational website

These pages contain no analytics scripts, sign-in forms, cookies set by the application, or file-upload functions. The website hosting provider may process ordinary request logs under its own policy.
