MacFiles Backup

MacFiles Backup is a private backup tool operated by its owner. It uses restic and rclone to save encrypted, versioned backups of the owner's selected files to the owner's Google Drive account and to restore those backups when needed.

The tool requests the Google Drive drive.file permission. This permits access to files created by the app or explicitly made available to it. The configured backup workflow uses only its own backup folder; it does not request access to all existing Drive files.

File contents and backup filenames are encrypted before upload. The decryption secret is stored separately from Google Drive.

This is a private tool, not a public file-sharing service. This website provides information only and does not accept uploads, run Google sign-in, or provide access to any backup.
